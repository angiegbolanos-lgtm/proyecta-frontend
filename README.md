# Proyecta — Plataforma de Gestión de Tareas y Proyectos (Frontend)

> *«Organiza tus tareas, conecta tus ideas y alcanza tus proyectos»*

Interfaz web frontend desarrollada con **React**, **Vite**, **React Router**, **Tailwind CSS** y **Lucide React**, con navegación entre Dashboard, Proyectos y Tareas, filtros combinados y validación de formularios con datos simulados.

## Requisitos previos

* **Node.js** (versión 18 o superior recomendada)
* **npm** (incluido con Node.js)
